# CyberChat

CyberChat is a frontend-only chatbot interface built with HTML, CSS and vanilla JavaScript. The project keeps the original dark rainbow UI while organizing the code into a more professional structure for GitHub Pages.

## Structure

- [index.html](index.html) — main app shell
- [css/styles.css](css/styles.css) — visual design and layout
- [js/app.js](js/app.js) — message rendering and input handling
- [js/chatbot.js](js/chatbot.js) — local rule-based chatbot engine
- [js/utils.js](js/utils.js) — small shared helpers
- [data/knowledge.json](data/knowledge.json) — chatbot knowledge loaded dynamically

## Features

- Dark rainbow visual theme preserved
- Local rule-based chatbot responses without any backend or API
- Dynamic knowledge loading from JSON
- Works directly on GitHub Pages with no dependencies
